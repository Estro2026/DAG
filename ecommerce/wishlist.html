⚙ Dev Notes — wishlist.html ★★★☆ Effort medio-alto YITH Wishlist WooCommerce Account required ▾

Plugin consigliato: YITH WooCommerce Wishlist

  • Free: una sola lista per utente — shortcode [yith_wcwl_wishlist] nella pagina wishlist
  • Premium (~€99/anno): liste multiple per utente, nomi personalizzabili, condivisione via link, wishlist pubblica/privata — necessario per questo wireframe
  • Alternativa: TI WooCommerce Wishlist (gratuito con liste multiple) — meno maturo, meno supporto Elementor
  • Senza account utente: wishlist salvata in cookie/localStorage — si perde al logout o cambio browser. Consigliare la registrazione
  • Il pulsante "Aggiungi alla wishlist" va aggiunto tramite hook WooCommerce: woocommerce_after_add_to_cart_button o con YITH automaticamente nei template

Flusso utente (questo wireframe)

  • Stato A (con prodotti): sidebar con le liste, griglia prodotti salvati, CTA "Aggiungi al carrello" per singolo item
  • Stato B (lista vuota): empty state con CTA verso shop — mostrato quando lista attiva è vuota
  • Creare lista: modal overlay → inserisci nome → crea → la lista appare nella sidebar (solo Premium)
  • Rimuovere prodotto: tasto × in overlay sull'immagine → prodotto sparisce dalla lista (AJAX via YITH)
  • Spostare prodotto tra liste: funzione Premium — non mostrata in wireframe ma da prevedere nel template
  • Condivisione: URL univoco per wishlist pubblica — /wishlist/[token]/ — YITH Premium genera il link automaticamente
  • Aggiunta al carrello dalla wishlist: AJAX — item rimane in wishlist fino a rimozione manuale (comportamento YITH default)

Elementor / WordPress

  • Pagina wishlist: creare pagina WordPress "Wishlist" con slug /wishlist/, inserire shortcode YITH nel contenuto (o blocco Gutenberg)
  • Elementor: YITH fornisce widget nativo per Elementor nella versione Premium
  • Template sidebar con liste: richiede custom template YITH o override PHP in tema child
  • CSS wishlist: sovrascrivere stili YITH nel tema child — molti elementi hanno classi .yith-wcwl-*
  • Impostare la pagina wishlist in: YITH → Wishlist → Impostazioni → Pagina wishlist

Permessi e stato login

  • Utente non loggato: mostrare modale di login prima di consentire l'aggiunta — evita wishlist anonime disperse
  • Configurabile in YITH: Wishlist → Impostazioni → Wishlist per utenti non loggati → Reindirizza al login
  • Questo wireframe mostra lo stato "utente loggato" — wireframing separato per flow non autenticato non necessario, basta nota
